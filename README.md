# Homework: Composition over Inheritance

This repository contains the implementation of the employee compensation example using two different object-oriented design approaches Inheritance and Composition.

## Project Structure

* `inheritance/`: Contains the strict class hierarchy version (IS-A).
* `composition/`: Contains the refactored version using aggregation and delegation (HAS-A).


## How to Run

Both versions are written in Python and require no external dependencies.

**To run the Inheritance version:**
Navigate to the inheritance folder from the root directory and execute the main file:
```bash
cd inheritance
python main.py
